## Free test tokens (open mint)

Both test tokens are mocks with **unrestricted** `mint(address,uint256)` — mint yourself as much as you like:

| Token | Address | Decimals |
|---|---|---|
| Mock USDT | `0x9896AF08d261E52a629EF58cBebd32E8e0AA8eA9` | 18 |
| Mock BTCB | `0x32fCF6a260Cdd2A3dc79cD0d4aD6B6c46bF6798A` | 18 |

```sh
# 200,000 USDT to yourself
cast send 0x9896AF08d261E52a629EF58cBebd32E8e0AA8eA9 \
  "mint(address,uint256)" $YOUR_ADDR 200000ether \
  --rpc-url https://bsc-testnet.bnbchain.org --private-key $PK \
  --legacy --gas-price 200000000

# 1 BTCB to yourself
cast send 0x32fCF6a260Cdd2A3dc79cD0d4aD6B6c46bF6798A \
  "mint(address,uint256)" $YOUR_ADDR 1ether \
  --rpc-url https://bsc-testnet.bnbchain.org --private-key $PK \
  --legacy --gas-price 200000000
```

This is a testnet-only convenience; mainnet will use real BTCB and USDT.

## Known quirks

<Warning>
**Legacy gas only.** BSC testnet public nodes mishandle EIP-1559 fee fields (the chain reports a zero base fee), so 1559-typed transactions fail with `insufficient funds: have 0`. Send **every** transaction on chain 97 as a legacy transaction at 0.2 gwei:

- `cast`/`forge`: `--legacy --with-gas-price 200000000` (`--gas-price` for `cast send`)
- viem: force `{ type: "legacy", gasPrice: 200000000n }` (the protocol's TS SDK does this automatically on chain 97)
</Warning>

<Warning>
**Flaky public RPCs.** The public endpoints are load-balanced across lagging nodes — expect occasional `nonce too low` errors and slow receipts. Prefer a keyed endpoint (e.g. thirdweb) and use retries (`--retries 12 --delay 5` with Foundry).
</Warning>

Other testnet-only trust assumptions worth knowing:

- The feed signer is **1-of-1** and the vol surface is a flat 60% IV fit — see [Oracles & feeds](/reference/oracles#testnet-caveats).
- The deployed OI fee (10% of notional) is a **placeholder under review** — see [Fees](/reference/fees).

## Running the services against testnet

Each service reads:

```sh
CHAIN_ID=97
RPC_URL=<rpc>
DEPLOYMENTS_PATH=protocol/deployments/97.json
# plus the relevant keys (executor for rfq-engine, signer for oracle-feeds)
```

Market makers: the [runbook](/market-makers/runbook) walks from a fresh key to a live quote in ~30 minutes.
