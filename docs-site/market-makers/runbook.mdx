**Prerequisites:** Node 22, pnpm, Foundry's `cast`, a fresh EOA key, ~0.05 tBNB from a faucet — and your maker address **registered on the engine allowlist** (send it to the team; un-allowlisted addresses are refused at WS auth with close code `4003` — see [Onboarding](/market-makers/onboarding#what-you-need)).

<Steps>
  <Step title="Clone + install (~5 min)">
    ```sh
    git clone <repo> && cd <repo>/services
    pnpm install
    pnpm --filter @hedge/shared build
    pnpm --filter @hedge/maker-bot build
    ```
  </Step>
  <Step title="Set the environment">
    Every maker-bot command reads these:

    ```sh
    export CHAIN_ID=97
    export RPC_URL=https://bsc-testnet.bnbchain.org     # or your thirdweb endpoint
    export PRIVATE_KEY=0x<your maker key>
    export RFQ_ENGINE_WS=wss://<engine-host>/maker      # ask the team for the current testnet host
                                                        # (ws://127.0.0.1:3030/maker against a local engine)
    ```
  </Step>
  <Step title="Mint yourself collateral (~2 min)">
    The mocks are open-mint:

    ```sh
    cast send 0x9896AF08d261E52a629EF58cBebd32E8e0AA8eA9 \
      "mint(address,uint256)" $(cast wallet address $PRIVATE_KEY) 200000ether \
      --rpc-url $RPC_URL --private-key $PRIVATE_KEY --legacy --gas-price 200000000
    ```
  </Step>
  <Step title="One-time setup: subaccount + cash (3 txs, ~2 min)">
    ```sh
    DEPOSIT_USDT=150000 pnpm --filter @hedge/maker-bot setup
    # -> "[setup] done: subaccount=<N> cash=150000 USDT"; id persisted to maker-state.97.json
    ```
  </Step>
  <Step title="Sanity-check pricing offline (no chain, no WS)">
    ```sh
    pnpm --filter @hedge/maker-bot exec maker-bot price \
      --forward 62790 --strike 69000 --days 8 --vol 0.6 --rate 0.05
    # -> { theo: ~398, bid: ~378 (0.95x), ask: ~418 (1.05x) }
    ```
  </Step>
  <Step title="Freshen the Pyth BTC spot price">
    The SRM's spot feed is a Pyth adapter with a **60 s staleness bound** — a stale price makes `getSpot()` revert, which fails margin checks and therefore fills. Push a fresh update whenever the price is more than 60 s old (any funded key works; it only pays gas):

    ```sh
    FEED_SIGNER_KEY=$PRIVATE_KEY pnpm --filter @hedge/oracle-feeds pyth-push
    ```

    Ops keep this fresh on the shared testnet engine, but run it yourself before triggering test auctions. See [Oracles & feeds](/reference/oracles).
  </Step>
  <Step title="Run the bot">
    ```sh
    pnpm --filter @hedge/maker-bot dev
    # [maker-bot] chain=97 owner=0x... subaccount=N
    # [transport] authenticated as 0x...
    # ...waits for rfq_open, prices off the on-chain feeds, quotes automatically
    ```
  </Step>
  <Step title="(Optional) trigger a test auction yourself">
    From a second, taker-side subaccount:

    ```sh
    curl -s -X POST https://<engine-host>/rfq -H 'content-type: application/json' -d '{
      "subaccountId": "<takerSubId>",
      "instrument": { "asset": "BTC", "expiry": 1781856000, "strike": "69000", "isCall": true },
      "amount": "1", "direction": "sell" }'
    # watch the bot log: quoted ... -> auction closed ... WON -> executed on-chain tx=0x...
    ```

    RFQ creation is rate-limited per IP (default 30/min) and can be disabled engine-side (`TAKER_OPEN=false`) — over-limit requests get `429`.
  </Step>
</Steps>

## Tuning knobs (env)

| Variable | Default | Meaning |
|---|---|---|
| `MAKER_BID_RATIO` | `0.95` | Bid as a fraction of Black-76 theo |
| `MAKER_ASK_RATIO` | `1.05` | Unused until maker-sell flow ships |
| `MAKER_MAX_FEE` | `"0"` | Signed `maxFee` (keep 0 — module fee is 0 today) |
| `QUOTE_TTL_SEC` | `300` | Quote TTL — see [Quote TTLs](/market-makers/risk-ops#quote-ttls) |
| `FORWARD_PRICE` / `SPOT_PRICE` / `IV` / `RATE` | — | Pricing overrides. When forward-or-spot **and** IV are set, the chain feeds are not queried at all — handy for dry runs. |

## Running your own engine (local dev)

For conformance testing against a local rfq-engine, the engine's env surface (its README in `services/rfq-engine` is canonical):

| Variable | Default | Meaning |
|---|---|---|
| `HOST` | `127.0.0.1` | Listen address — keep loopback in dev; `0.0.0.0` only behind a TLS-terminating reverse proxy |
| `RFQ_PORT` / `PORT` | `3030` | HTTP + WS listen port |
| `AUCTION_WINDOW_MS` | `3000` | Quote-collection window per RFQ |
| `TAKER_ACCEPT_DEADLINE_MS` | `120000` | Taker-accept deadline after close; past it the RFQ expires and the maker is released |
| `WS_HEARTBEAT_MS` | `30000` | WS ping interval (`0` disables) |
| `MAKER_ALLOWLIST` | empty (open/dev) | Comma-separated maker EOAs; other addresses refused with close code `4003` |
| `TAKER_OPEN` | `true` | `false` rejects all RFQ creation (`403` / taker-WS error) |
| `RFQ_RATE_LIMIT_PER_MIN` | `30` | RFQ creations per IP per minute (`0` disables) |
| `STORE_PATH` | unset (in-memory) | JSONL file for durable auctions + trade history with crash recovery |
| `EXECUTOR_PRIVATE_KEY` | anvil key #0 (31337 only) | Must be the registered trade executor |

## Adapting the reference bot

The only protocol-shaped code in the bot is:

- `src/transport.ts` — WS framing + auth handshake
- `src/quoter.ts` — order encoding + signing

Replace `src/pricing.ts` / `src/black76.ts` with your own pricer and keep the other two. Or port the [wire protocol](/market-makers/wire-protocol) and [signing](/market-makers/signing) pages to your own stack and use `scripts/fake-engine.mjs` — a one-shot local engine that runs the handshake, broadcasts one RFQ, and prints your quote — as a conformance test for your client.
