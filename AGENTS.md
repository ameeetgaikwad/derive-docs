# Repository Guidelines

## Git Authorization

- Never stage files, create commits, amend commits, push branches, create or merge pull requests, switch or create branches, rebase, tag, or otherwise mutate Git state unless the user explicitly requests that exact action.
- A request to implement, deploy, release, publish, or make a feature live does not implicitly authorize any Git operation.
- Read-only Git inspection is allowed when relevant.
- After completing file changes, report the changed files and wait for explicit Git instructions.
